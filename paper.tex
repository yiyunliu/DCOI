\section{\name}

In this section, we present the grammar and judgements of \name,
which is an instantiation of the \longname (\dcoi)~\citep{liu:dcoi} with
the Pure Type System (PTS)~\citep{barendregt:PTS} axioms and rules
of a predicative universe hierarchy.
The grammar is given in \cref{fig:grammar},
which is parameterized over a meet-semilattice of dependency levels
(following \citet{abadi:dependency}).

\begin{figure}[h]
\begin{alignat*}{2}
  [[G]], [[D]] & \Coloneqq [[nil]] \mid [[G ++ x : l A]] & \quad & \text{Typing contexts with levels and types} \\
  [[E]], [[F]] & \Coloneqq [[nil]] \mid [[E ++ x : l]] & \quad & \text{Grading contexts with levels} \\
  [[A]], [[B]], [[C]], &&& \\
  [[a]], [[b]], [[c]], [[p]] & \Coloneqq & \quad & \text{Terms} \\
  & \mid [[x]] \mid [[Univ i]] \mid [[Void]] \mid [[absurd b]] & \quad & \textit{variables, type universes, empty type, absurd} \\
  & \mid [[Pi x : l A . B]] \mid [[\ l x . b]] \mid [[b l a]] & \quad & \textit{function types, abstractions, applications} \\
  & \mid [[Sig x : l A . B]] \mid [[(l a, b)]] \mid [[let (l0 x, y) = l a in b]] & \quad & \textit{pair types, pairs, matching} \\
  & \mid [[a ~ l b : A]] \mid [[refl]] \mid [[J c l p]] \mid [[down l p]] & \quad & \textit{equality types, reflexivity, J eliminator, downgrade}
\end{alignat*}
\caption{Grammar of contexts and terms}
\label{fig:grammar}
\end{figure}

We use the metavariable $[[l]]$ for dependency levels,
and $[[l0 /\ l1]]$ for the meet of $[[l0]]$ and $[[l1]]$.
As in the previous section, we use the low $[[L]]$ and high $[[H]]$ levels in our examples,
with $[[L < H]]$.
Similarly, we use the metavariables $[[i]], [[j]], [[k]]$ for universe levels,
which we take to be meta-level naturals,
and $[[max i j]]$ for the maximum of $[[i]]$ and $[[j]]$.
Although our mechanization uses de Bruijn indices for representing binding
and simultaneous substitutions,
for clarity we use named variables and single substitutions for our presentation.
We use the metavariables $[[x]], [[y]], [[z]]$ for variables
and $[[a { b / x }]]$ for the substitution of a term $[[b]]$ in place of the variable $[[x]]$
inside the term $[[a]]$.

% there are a number of other differences from \dcoi in the syntax of \name,
% highlighted in yellow.
% We add an empty type and its eliminator,
% which enables using some higher-level terms at lower levels.
% We also replace pair projections with a pair-matching expression,
% and substitution over equality proofs with a full J eliminator.
% Finally, we add a downgrade operator on equality proofs,

The main judgement is the typing judgement,
which has the form $[[G |- a : l A]]$ for a term $[[a]]$
that is well type under context $[[G]]$ at level $[[l]]$
with type $[[A]]$.
To reduce clutter,
we use the judgement $[[G |- a : A]]$ to mean that there exists some level $[[l]]$
such that $[[G |- a : l A]]$ holds.
The typing rules are defined mutually with the context well-formedness rules,
both given in \cref{fig:typing:dep}.
When viewed as a PTS, the \rref{Wt-Univ,Wt-Pi} correspond
to the sort axioms $([[Univ i]], [[Univ i + 1]])$ for every $[[i]]$
and the sort rules $([[Univ i]], [[Univ j]], [[Univ max i j]])$ for every $[[i]], [[j]]$.

\begin{figure}[h]
  \drules[Wf]{$[[ |- G]]$}{Context well-formedness}{Nil, Cons}
  \drules[Wt]{$[[G |- a : l A]]$}{Well-typedness}{Var,Univ,Empty,Absurd,Pi,Abs,App}
  \caption{Well-formedness and typing rules (universes, empty, functions)}
  \label{fig:typing:dep}
\end{figure}

Deferring our discussion of using levels for dependency tracking to \cref{sec:dep},
the remaining rules for variables, function abstractions, function applications,
the empty type, and its eliminator are standard for dependent type theory.
To change the type of a term to an equivalent one,
typing uses a definitional equality that is defined in terms of indistinguishability (\cref{sec:indist}).
We then look at the rules for dependent pair types (\cref{sec:pairs}),
and finally for propositional equality types (\cref{sec:eq}),
which internalize indistinguishability.

\subsection{Definitional equality and indistinguishability} \label{sec:indist}

\begin{figure}[h]
  \drule{Wt-Conv} % maybe this should go back in the previous figure
  \drule{E-Conv}
  \drule{P-AppAbs}
  \vspace{0.5\baselineskip}
  \caption{Conversion, definitional equality, and parallel reduction ($\beta$ only) rules}
  \label{fig:conv}
\end{figure}

The typing rules also include \rref{Wt-Conv}, shown in \cref{fig:conv},
wich allows converting the type of a well-typed term to a definitionally equal type.
Our definitional equality is untyped, but eventually relies on the levels of variables,
so its judgement form $[[E |- a == b]]$ requires a grading context $[[E]]$.
In \rref{Wt-Conv}, this is provided by $[[| G |]]$,
which denotes dropping all type annotations to convert a typing context into a grading context.

Definitional equality is defined by \rref{E-Conv} in \cref{fig:conv},
which separately incorporates parallel reduction and indistinguishability.
Parallel reduction consists of the $\beta$-reduction rules for our elimination forms,
listed in \cref{fig:conv} and in following subsections,
along with rules for the reflexive, congruent closure, omitted here.
Multi-step parallel reduction $[[a =>* b]]$ is then the transitive closure of parallel reduction.
This formulation of equality is in contrast to the system by \citet{liu:dcoi},
where parallel reduction is merely a metatheoretic tool for proving type safety.

\begin{figure}[h]
  \drules[I]{$[[E |- a == b @ l]]$}{Indistinguishability}{Var,Univ,Empty,Absurd,Pi,Abs,App}
  \drules[GI]{$[[E |- a == b @ l l0]]$}{Guarded indistinguishability}{Dist,Indist}    
  \caption{(Guarded) indistinguishability rules (universes, empty, functions)}
  \label{fig:indist}
\end{figure}

Indistinguishability is mutually defined with guarded indistinguishability,
given in \cref{fig:indist}.
Guarded indistinguishability is used in \rref{I-App};
otherwise, two terms are indistinguishable at observer level $[[l]]$
if they have the same shape and their subterms are also indistinguishable at $[[l]]$.

We say that indistinguishability is \emph{coarser} than mere $\alpha$-equivalence
(and hence $[[E |- a == b]]$ is coarser than mere $\beta$-equivalence of $[[a]]$ and $[[b]]$)
because more terms may be indistinguishable while not necessarily being $\alpha$-equivalent.
This is because the use of guarded indistinguishability when comparing arguments in \rref{I-App},
which are labelled at $[[l0]]$, but observed at $[[l]]$.
If $[[l0 <= l]]$, meaning that the observer can fully see the arguments,
then \rref{GI-Dist} applies, and the applications are indistinguishable
if both the functions and the arguments are indistinguishable at $[[l]]$ respectively.
Otherwise, if $[[not (l0 <= l)]]$, then \rref{GI-Indist} applies,
and the arguments are too high to be observed at $[[l]]$,
so indistinguishability of the applications does not consider the arguments.
As a simple example,
$[[:concrete: (# w : L ++ x : H #) ++ y : H |- (\ H z . w) H x == (\ H z . w) H y @ L]]$
holds even though $[[x]]$ and $[[y]]$ could be anything,
because the observer level is $[[L]]$,
while the arguments' levels are $[[H]]$ and therefore unobservable.
Indistinguishability of unobservable arguments articulates the intuition that
since functions cannot meaningfully use unobservable arguments,
they may safely be ignored.

A level comparison also occurs in \rref{I-Var},
where a variable may only be indistinguishable from itself
if the observer level is high enough to observe it.
This prevents equating arbitrary terms via function applications, such as
$[[:concrete: x : H ++ y : H |- (\ H z . z) H x == (\ H z . z) H y]]$,
since the bodies of the functions are not indistinguishable.
Without this level comparison,
we have via \rref{E-Conv} the equalities $[[nil |- Unit == (\ H z . z) H Unit]]$,
$[[nil |- (\ H z . z) H Unit == (\ H z . z) H Void]]$,
and $[[nil |- (\ H z . z) H Void == Void]]$,
which would permit a closed term of $[[Void]]$ via repeated applications of \rref{Wt-Conv}.

\section{Syntactic metatheory}

% TODO: Rewrite this paragraph
In this section, we develop the metatheory of \name.
Our ultimate goals are weak normalization,
that all well-typed terms reduce to a normal form;
and logical consistency,
that there is no closed term of the empty type.
We begin with proving various syntactic properties of our judgements,
culminating in subject reduction,
that a well-typed term remains well typed after reduction.
We then establish a logical relation between types and sets of terms,
and define semantic typing in terms of the logical relation.
Normalization and consistency follow as corollaries of the fundamental theorem,
which states that syntactic typing implies semantic typing.

All of the metatheory has been mechanized in Coq.
The development can be found in \repo{} under the \texttt{proofs} directory.
Definitions, lemmas, and theorems given here are annotated with a footnote
to the corresponding file and top-level name in the development.
Some lemmas are presented as admissible derivation rules of the corresponding judgement,
which are written with a double horizontal bar instead of a single bar.
Their corresponding mechanizations are annotated where mentioned in the prose.

While we continue to used named variables rather than de Bruijn indices,
to bring the presentation closer to the mechanization,
in this section we frame substitution in terms of \emph{substitution maps}
(or simply \emph{substitutions} for short)
and simultaneous substitutions.

\begin{definition}[Substitution maps]
  A substitution map $\rho$ is a mapping from variables to terms.
  We use $\dom(\rho)$~to denote the variables in the domain of $\rho$,
  $\rho(x)$~the term to which $\rho$ maps $[[x]]$,
  $[[nil]]$~the identity substitution map,
  $[[(rho ++ { a / x })]]$~the extension of $[[rho]]$
  by a mapping from $[[x]]$ to $[[a]]$,
  and $[[a { rho }]]$~the simultaneous substitution
  of the variables $x \in \dom(\rho)$ in $[[a]]$ by $\rho(x)$.
\end{definition}

The singleton substitution map $[[{ a / x }]]$ is then defined as $[[(nil ++ { a / x })]]$,
the single extension of the identity substitution map.

\subsection{Properties of parallel reduction}

The notion of parallel reduction can be extended to substitution maps
pointwise on each term in the maps.

\begin{definition}[Parallel reduction of substitutions]
  A substitution map $[[rho0]]$ parallel reduces to $[[rho1]]$,
  written $[[rho0 => rho1]]$, if $[[rho0(x) => rho1(x)]]$ for every $[[x]]$.
  Similarly, $[[rho0 =>* rho1]]$ if $[[rho0(x) =>* rho1(x)]]$ for every $[[x]]$.
\end{definition}

We then prove the morphing lemmas
\rref*{P-morph}\footnote{\suppl{theories}{par.v}{Par\_morphing}} and
\rref*{Ps-morph}\footnote{\suppl{theories}{par.v}{Pars\_morphing\_star}},
listed in \cref{fig:pars-lemmas},
which combine a reducing term with a reducing substitution map.
The substitution lemma
\rref*{P-morph}\footnote{\suppl{theories}{par.v}{Par\_cong}},
which combines two reducing terms by substitution,
then follows from morphing.
An additional useful lemma is that single parallel reduction itself is already reflexive
(\rref*{P-refl}\footnote{\suppl{theories}{par.v}{Par\_refl}}).

\begin{lemma}[Diamond]
  \stack{.~}\footnote{\suppl{theories}{par.v}{Par\_confluent}}
  \label{lem:diamond}
  If $[[a => b0]]$ and $[[a => b1]]$, then
  there exists some $[[c]]$ such that $[[b0 => c]]$ and $[[b1 => c]]$.
\end{lemma}

\begin{lemma}[Confluence]
  \stack{.~}\footnote{\suppl{theories}{par.v}{Pars\_confluent}}
  \label{lem:confluence}
  If $[[a =>* b0]]$ and $[[a =>* b1]]$, then
  there exists some $[[c]]$ such that $[[b0 =>* c]]$ and $[[b1 =>* c]]$.
\end{lemma}

\subsection{Well-gradedness and substitution}

As indistinguishability and definitional equality involve a grading context,
we require a well-gradedness judgement on terms to be able to prove some substitution lemmas.
The judgement specifies the dependency level that a term may be assigned.
In later sections, we will see that semantic typing and the logical relation
also need to carry around some well-gradedness information.
The rules for the judgement can be seen as the same as the typing rules,
but with all typing information stripped out, leaving only the levels,
and are listed in \cref{fig:grading}.

\begin{figure}[h]
  \drules[Wg]{$[[E |- a : l]]$}{Term well-gradedness}{Var,Univ,Empty,Absurd,Pi,Abs,App,Eq,Refl,J,Down,Sig,Pair,Let}
  \caption{Term grading rules}
  \label{fig:grading}
\end{figure}

Just as terms have notions of well-gradedness and indistinguishability,
so too do substitution maps.
The intuition is that a substitution map is a transformation from one grading context to another,
and two substitution maps are indistinguishable by some observer
if the terms they substitute in are indistinguishable by that observer.

\begin{definition}[Substitution well-gradedness]
  A substitution map $[[rho]]$ for a grading context $[[F]]$
  under a grading context $[[E]]$ is well-graded,
  written $[[E |- rho : F]]$,
  if for every $[[x : l in F]]$,
  $[[E |- rho(x) : l]]$ holds.
  We also say that $[[rho]]$ is a substitution map from $[[F]]$ to $[[E]]$.
\end{definition}

\begin{definition}[Substitution indistinguishability]
  Two substitution maps $[[rho0]], [[rho1]]$
  for a grading context $[[F]]$ under a grading context $[[E]]$
  are indistinguishable at level $[[l]]$, written $[[E |- rho0 == rho1 : F @ l]]$,
  if for every $[[x : l0 in F]]$,
  $[[E |- rho0(x) == rho1(x) @ l l0]]$ holds.
\end{definition}

  \drule{Sg-weak}
  \drule{SI-nil}

  \vspace{0.5\baselineskip}
  \caption{Admissible rules for well-gradedness and indistinguishability of substitutions}

\end{figure}

These judgements satisfy some standard properties,
listed as admissible rules in \cref{fig:subst-lemmas}.
They assert that identity substitutions indeed do not change the grading context
(\rref*{Sg-nil}\footnote{\suppl{theories}{geq.v}{iok\_subst\_nil}})
and are indistinguishable from one another
(\rref*{SI-nil}\footnote{\suppl{theories}{geq.v}{ieq\_subst\_nil}});
well-graded substitutions can be extended with a single substitution by a well-graded term
(\rref*{Sg-cons}\footnote{\suppl{theories}{geq.v}{iok\_subst\_cons}});
indistinguishable substitutions can be extended with single substitutions by indistinguishable terms
(\rref*{SI-cons}\footnote{\suppl{theories}{geq.v}{ieq\_subst\_cons}});
and the context under which substitutions act can be weakened
(\rref*{Sg-weak,SI-weak}\footnote{\suppl{theories}{geq.v}{iok\_subst\_ok\_suc}, \suppl{theories}{geq.v}{ieq\_morphing\_helper}}).

\subsection{Properties of grading, indistinguishability, and definitional equality}

The well-gradedness, indistinguishability, and definitional equality judgements
satisfy some standard properties,
listed as admissible rules in \cref{fig:grading-lemmas},
\cref{fig:defeq-lemmas}, and \cref{fig:indist-lemmas}, respectively.

Indistinguishability is reflexive for well-graded terms
(\rref*{I-refl}\footnote{\suppl{theories}{geq.v}{iok\_ieq}}),
symmetric (\rref*{I-sym}\footnote{\suppl{theories}{geq.v}{ieq\_sym\_mutual}}),
and transitive (\rref*{I-trans}\footnote{\suppl{theories}{geq.v}{ieq\_trans\_heterogeneous}}).
Transitivity is slightly more general in its observer level:
given a chain of three indistinguishable terms at two different observer levels,
the end terms are indistinguishable at the meet of the levels.
% Proving transitivity relies on a downgrade property

This generalization is crucial for definitional equality,

A final key lemma of indistinguishability is the simulation property,
which enforces that indistinguishable terms must reduce in lockstep.

\begin{lemma}[Simulation]
  \stack{.~}\footnote{\suppl{theories}{conv.v}{simulation\_star}}
  \label{lem:simulation}
  If $[[E |- a0 == b0 @ l]]$ and $[[a0 =>* a1]]$,
  then there exists some $[[b1]]$ such that $[[b0 =>* b1]]$
  and $[[E |- a1 == b1 @ l]]$.
\end{lemma}

An important consequence of simulation
is that reduction of definitionally equal terms preserves definitional equality
(\rref*{E-pres}\footnote{\suppl{theories}{conv.v}{iconv\_par2}}).
Because definitional equality is defined in \rref{E-Conv}
as the indistinguishability of the two terms after parallel reduction,
the proof uses \nameref{lem:confluence}.

As with indistinguishability,
definitional equality is reflexive for well-graded terms
(\rref*{E-refl}\footnote{\suppl{theories}{conv.v}{conv\_refl}}),
symmetric (\rref*{E-sym}\footnote{\suppl{theories}{conv.v}{conv\_sym}}),
and transitive (\rref*{E-trans}\footnote{\suppl{theories}{conv.v}{conv\_trans}}).
Inverting the premises of transitivity,
each of them independently have some level at which two terms are indistinguishable,
so combining them requires the more general transitivity of \rref*{I-trans}.
The proof also relies on simulation.

\end{lemma}

\begin{lemma}[Injectivity of pair types]
  \stack{.~}\footnote{\suppl{theories}{conv.v}{conv\_sig\_inj}}
  If $[[E |- Sig x : l0 A0 . B0 == Sig x : l1 A1 . B1]]$
  then $[[l0]] = [[l1]]$, $[[E |- A0 == A1]]$,
  and $[[E ++ x : l0 |- B0 == B1]]$.
\end{lemma}

\begin{lemma}[Injectivity of equality types]
  \stack{.~}\footnote{\suppl{theories}{conv.v}{conv\_eq\_inj}}
  If $[[E |- a0 ~ l0 b0 : A0 == a1 ~ l1 b1 : A1]]$
  then $[[l0]] = [[l1]]$,
  and there exists an $[[l >= l0]]$
  such that $[[E |- a0 == a1 @ l]]$ and $[[E |- b0 == b1 @ l]]$.
\end{lemma}

\begin{lemma}[Injectivity of universes]
  \stack{.~}\footnote{\suppl{theories}{conv.v}{conv\_univ\_inj}}
  If $[[E |- Univ i == Univ j]]$ then $[[i]] = [[j]]$.
\end{lemma}

In this section, we use a logical predicate (Figure~\ref{fig:logpred}) to show weak
normalization and consistency for \name.
We structure the section as follows. In Section~\ref{sec:logpred}, we

\subsection{A logical predicate for \name}
\label{sec:logpred}
Before we can define the logical predicate, we need to first define
the notion of neutral and normal terms so we can characterize
semantically well-behaved terms.
% Before we can state and prove the adequacy property for the
% logical predicate, we need to first define normal and neutarl forms
% and prove some useful lemmas about how they interact with parallel
% reduction.

\begin{figure}[h]
  \centering

Figure~\ref{fig:normalform} defines neutral and normal forms in the
form of two judgments $[[ne a]]$ and $[[nf a]]$. These predicates
characterize a set of terms that are free of redexes. This property
can be formulated using parallel reduction as follows.
\begin{lemma}
  \stack{.~}\footnote{\suppl{theories}{normalform.v}{nf\_refl}}
  If $[[nf a]]$ or $[[ne a]]$, then for all $[[b]]$ such that $[[a =>
  b]]$, we have $[[a]] = [[b]]$.
\end{lemma}

\begin{definition}[Terms that are weakly normalizing]
  Given a term $[[a]]$, if there exists some term $[[b]]$ such that
  $[[a =>* b]]$, then we say that $[[a]]$ weakly normalizes to a
  normal (resp. neutral) form, which we denote in judgment form as
  $[[wnf a]]$ (resp. $[[wne a]]$).
\end{definition}

We are now ready to give the definition of our logical relation.
Similar to \citet{abel:irrelevance}'s semantic interpretation of types, 
we define our logical predicate, which takes the form
$\interp{[[E]]}{[[i]]}{[[A]]}{S}$, as an inductive relation
recursively defined over the universe level $[[i]]$. The
metavariable $S$ represents a family of terms indexed by levels. 
We use the notation $\member{a}{[[l]]}{S}$ to indicate that $[[a]]$ is
a term that belongs to the set in $[[S]]$ that is indexed by $[[l]]$.
The judgment $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ reads that under the
grading context $[[E]]$ and universe level $[[i]]$, the type $[[A]]$
can be interpreted as the family of sets $[[S]]$.

Unlike logical relations for simply typed languages, the logical
predicate for \name cannot be defined as a total function since not
all terms can be assigned a meaning. Instead, the logical predicate
$\interp{[[E]]}{[[i]]}{[[A]]}{S}$ simultaneously specifies the
semantically well-formed types $[[A]]$ and its meaning $[[S]]$. %  A key
% result we will present later in this section is the functionality of
% the logical predicate; that is, each term can only correspond to one
% interpretation $[[S]]$ if there exists one.

We use the following definition in our discussion to reduce the noise
introduced by the partiality of the logical predicate.
\begin{definition}[Semantic inhabitance]
  Given a context $[[E]]$ and a level $[[l]]$, 
  we say that $[[a]]$ \emph{semantically inhabits} the type $[[A]]$
  at level $[[l]]$ if there exists some $[[i]]$ and $[[S]]$ such that
  $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and $\member{a}{[[l]]}{S}$.
\end{definition}

In \rref{SWt-Pi,SWt-Sigma}, the
metavariable $R$ represents a relation between lambda terms and the
indexed family of terms $S$. Ignoring the conclusion of the rules, 
\rref*{SWt-Pi} and \rref*{SWt-Sigma} share the same preconditions,
which ensure their well-formedness in the following sense:
for every term $[[a]]$ that semantically inhabits the type $[[A]]$ at
level $[[l0]]$, the type $[[B {a / x}]]$ is well-formed. This
The
interpreted sets appearing in the conclusion follows our usual
intuition. In the function case, for example, the definition of $\prodspace$
specifies the semantic inhabitants of a function type as the set of
terms that, when applied to another term that semantically inhabits
the input type, gives us a term that semantically inhabits the output
type.

The logical predicate takes in the grading context $[[E]]$ as a
parameter to ensure that the $[[S]]$ only includes terms that are
well-graded with respect to the indexed level.
This property is
formally stated as follows and can be proven by straightforward
induction over the logical predicate.
\begin{lemma}[Escape]
  \stack{.~}\footnote{\suppl{theories}{semtyping.v}{InterpUniv\_Ok}}
  \label{lem:escape}
  If $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and $\member{[[a]]}{[[l]]}{S}$,
  then $[[E |- a : l]]$.
\end{lemma}
We refer to \cref{lem:escape} as the escape lemma as it is
reminiscent of the escape lemmas found in \citet{abel:irrelevance,
adjedj:mltt-coq}, though instead of escaping from the
logical predicate to the syntactic typing judgment, we only require
the much weaker well-gradedness judgment. The well-gradedness
restriction will be necessary for us to show that indistinguishable
types have the same meaning.
% The relaxation is possible thanks to
% the untyped conversion rule, which allows us % to derive properties
% like $\Pi$-injectivity through the syntactic
% approaches described in Section~\ref{sec:synmeta} independently of our
% semantic metatheory. However, the well-gradedness restriction is still
% required to justify the use of indistinguishability in the type
% conversion rule.

Next, we show some properties which will be useful in
\cref{sec:soundness} for the proof of the fundamental
theorem. We omit some uses of the syntactic lemmas from
\cref{sec:synmeta} about reduction and indistinguishability
when presenting the proof sketches.
% The logical predicate is specified as an inductive relation, but we
% can further show that it is in fact a partial function; that is, given
% a grading context $[[E]]$, every type $[[A]]$ can only correspond to
% one unique interpretation $[[S]]$ if there exists one. We establish
% this fact through the following sequence of lemmas, all of which can

The logical predicate satisfies the following inversion principles. 
These inversion principles are not immediately obtainable by inverting
the derivation because we close our interpretation with full
reduction in \rref{SWt-Step}. For brevity, we only show the cases
for equality, function, and empty types.
\begin{lemma}[Inversion of the logical predicate (selected)]
  \label{lem:interpinv}\leavevmode
  \begin{enumerate}
  \item If $\interp{[[E]]}{[[i]]}{[[a ~ l0 b : A]]}{S}$, then $S =
    \buildset{[[p]]}{[[l]]}{[[E |- p : l]] \wedge (\eqspace([[p]],
      [[l0]], [[a]], [[b]], [[E]]) \vee [[wne p]])}$
  \item If $\interp{[[E]]}{[[i]]}{[[Pi x : l0 A . B]]}{S}$, then there
    exists $S_A$ and $R$ such that following holds:
    \begin{itemize}
    \item $S = \buildset{[[b]]}{[[l]]}{[[E |- b : l]] \wedge \prodspace([[b]], [[l]], [[l0]], S_A, R)}$
    \item $\interp{[[E]]}{[[i]]}{[[A]]}{S_A}$
    \item $\forall a, \member{a}{[[l0]]}{S_A} \to \exists S_B, R(a,
      S_B)$
    \item $\forall a, S_B, \member{a}{[[l0]]}{S_A} \to R(a, S_B) \to
      \interp{[[E]]}{[[i]]}{[[B {a / x}]]}{S_B}$
    \end{itemize}
  \item If $\interp{[[E]]}{[[i]]}{[[Void]]}{S}$, then $S =
    \buildset{[[a]]}{[[l]]}{[[E |- a : l]] \wedge [[wne a]]}$
  \item \ldots
  \end{enumerate}
\end{lemma}
\begin{proof}
  Immediate by induction over the derivation of the logical
  predicate.
\end{proof}

The set of terms that semantically inhabit a type are closed by
expansion (i.e. backward reduction).
\begin{lemma}[Backward closure]
  \stack{.~}\footnote{\suppl{theories}{semtyping.v}{InterpUnivN\_back\_clos}}
  Suppose $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and $[[E |- a : l]]$.
  If $[[a => b]]$ and $\member{[[b]]}{[[l]]}{S}$,
  then $\member{[[a]]}{[[l]]}{S}$.
\end{lemma}
\begin{proof}
  By induction over the derivation of the logical predicate. The
  \texttt{SWt-Univ} case requires \texttt{SWt-Step}, the backward
  closure property baked into the definition of the logical
  predicate. All other cases are trivial.
\end{proof}

The logical predicate satisfies cumulativity; if a type has an
interpretation at a lower level, then it must also have the same
interpretation at a higher level.
\begin{lemma}[Cumulativity]
  If $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and $[[i]] \leq [[j]]$, then
  $\interp{[[E]]}{[[j]]}{[[A]]}{S}$.
\end{lemma}
\begin{proof}
  By induction on the derivation of $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and the transitivity of $\leq$.
\end{proof}

\Rref{SWt-Step} closes the interpretation of types under
expansion. We can also show that the meaning of types is
preserved under forward reduction through the following lemma.
\begin{lemma}[Reduction preserves meaning]
\label{lem:lrpreservation}
  If $\interp{[[E]]}{[[i]]}{[[A]]}{S}$ and $[[A => B]]$, then
  $\interp{[[E]]}{[[i]]}{[[A]]}{S}$.
\end{lemma}
\begin{proof}
  By induction over the derivation of
  $\interp{[[E]]}{[[i]]}{[[A]]}{S}$.
  \Rref{SWt-Step} is the only interesting case, where we
  leverage the diamond property \todo{add the diamond property} of
  parallel reduction to reconcile two potentially distinct reductions
  from the type $[[A]]$.
\end{proof}


Next, we prove that the logical predicate is functional. That is,
given a context $[[E]]$ and a universe level $[[i]]$, a type $[[A]]$
can correspond to at most one interpretation $[[S]]$.
\begin{lemma}[Functionality]
\label{lem:lrfunc}
If $\interp{[[E]]}{[[i]]}{[[A]]}{S_0}$ and
$\interp{[[E]]}{[[i]]}{[[A]]}{S_1}$, then $S_0 = S_1$.
\end{lemma}
\begin{proof}
  By induction over the derivation of
  $\interp{[[E]]}{[[i]]}{[[A]]}{S_0}$.
  The \rref*{SWt-Step} case is immediate by \cref{lem:lrpreservation}.
  For all other cases, the conclusion
  follows by applying the inversion
  properties (\cref{lem:interpinv}) on
  $\interp{[[E]]}{[[i]]}{[[A]]}{S_1}$.
\end{proof}

The logical relation is functional not only for types that are
syntactically equal, but also for types that are
indistinguishable. This property is needed to fully justify the
soundness of the type conversion rule since the type conversion
involves both reduction and indistinguishability.
\begin{lemma}[Functionality for indistinguishable types]
\label{lem:lrfunc}
If $\interp{[[E]]}{[[i]]}{[[A]]}{S_0}$,
$\interp{[[E]]}{[[i]]}{[[B]]}{S_1}$, and
$[[E |- A == B @ l ]]$ for some $[[l]]$,
then $S_0 = S_1$.
\end{lemma}
\begin{proof}
  The argument is similar to the one for Lemma~\ref{lem:lrfunc}.
  We start by induction over the derivation of
  $\interp{[[E]]}{[[i]]}{[[A]]}{S_0}$.
  For case \texttt{SWt-Step}, we need both Lemma~\ref{lem:lrpreservation}
  and the simulation property for indistinguishability
  (Lemma~\ref{lem:simulation}).
  For other cases, we apply the inversion properties on
  $\interp{[[E]]}{[[i]]}{[[B]]}{S_1}$.

  The function and sigma cases both require one extra step to complete the
  proof. Consider the case where $[[A]] = [[Pi x : l0 A0 . B0]]$ and
  $[[B]] = [[Pi x : l0 A1 . B1]]$. The
  induction hypothesis says that for every term $[[a]]$ that
  semantically inhabits $[[A0]]$, if a type $[[C]]$ is
  indistinguishable from $[[B0 {a / x}]]$, then $[[C]]$ and $[[B0 {a /
  x}]]$ have the same meaning. To complete the proof, we need to
  leverage the induction hypothesis by instantiating the variable
  $[[C]]$ with the type $[[B1 { a / x}]]$ and prove that $[[B0 {a /
    x}]]$ is indistinguishable from $[[B1 {a / x}]]$.  From the
  premise that $[[Pi x : l0 A0 . B0]]$ and $[[Pi x : l0 A1 . B1]]$ are
  indistinguishable, we already know that $[[B0]]$ and $[[B1]]$ are
  indistinguishable.

  To prove that $[[B0 {a / x}]]$ and $[[B1 {a / x}]]$ are
  indistinguishable, we want to apply
  the substitution rule for indistinguishability
  (\rref{I-subst}), which requires $[[a]]$ to be well-graded at $[[l0]]$.
  By Lemma~\ref{lem:escape}, the escape property, we finish the
  proof by deducing the well-gradedness of $[[a]]$ from the fact that
  $[[a]]$ semantically inhabits the input type $[[A0]]$.
\end{proof}

property, which establishes the connection between the inhabitants of

neutral forms.

Before we state and prove adequacy, we first show some
useful facts about normal forms. Following \citet{geuvers:cc-sn}, we
introduce a dummy constant $[[dummy]]$ to the set of untyped lambda
terms for presentation purposes. The dummy term satisfies the rules
specified in Figure~\ref{fig:dummy}.

Reductions and normal forms are preserved when we undo the substitutions
involving $[[dummy]]$.
\begin{lemma}[Antirenaming for Par]
  \label{lem:paranti}
  If $[[a {dummy / x} => b]]$, then there exists some term $[[b0]]$
  such that $[[b]] = [[b0 {dummy / x}]]$ and $[[a => b0]]$.
\end{lemma}
\begin{lemma}[Antirenaming for normal and neutral forms]
  \label{lem:nfneanti}
  If $[[nf a {dummy / x}]]$ (resp. $[[ne a {dummy / x}]]$), then $[[nf
  a]]$ (resp. $[[ne a]]$).
\end{lemma}
From Lemmas~\ref{lem:paranti} and \ref{lem:nfneanti}, we derive the
following corollary about weak normalization.
\begin{lemma}[Antirenaming for weak normalization]
  \label{lem:wnanti}
  If $[[wnf a {dummy / x}]]$ (resp. $[[wne a {dummy / x}]]$), then $[[wnf
  a]]$ (resp. $[[wne a]]$).
\end{lemma}

Finally, we state and prove the adequacy lemma.
\begin{lemma}[Adequacy]
  \label{lem:adequacy}
  If $\interp{[[E]]}{[[i]]}{[[A]]}{S}$, then the following holds:
  \begin{itemize}
  \item If $\member{a}{[[l]]}{S}$, then $[[wnf a]]$
  \item If $[[E |- a : l]]$ and $[[wne a]]$, then $\member{a}{[[l]]}{S}$
  \item $[[wnf A]]$
  \end{itemize}
\end{lemma}
\begin{proof}
  By induction over the derivation of
  $\interp{[[E]]}{[[i]]}{[[A]]}{S}$.
  The only interesting part of the proof is showing normalization for
  well-formed function and sigma
  types. We focus on the function type and the proof for sigma type is
  almost identical.

  In the function case, we have $[[A]] = [[Pi x : l0 A0 . B0]]$. By
  the induction hypothesis, we already know $[[wnf A0]]$ and for all
  terms $[[a]]$ that semantically inhabits $[[A0]]$, the term $[[B0 {a
    / x}]]$ is weakly normalizing. To show that $[[Pi x : l0 A0. B0]]$
  is weakly normalizing, it suffices to show that $[[B0]]$ is weakly
  normalizing. 

  Since the induction hypothesis about $[[B0]]$ is universally
  quantified, we need to find a concrete term to instantiate $[[a]]$
  with. By the induction hypothesis about $[[A0]]$, we also know that
  if $[[E |- a : l]]$ and $[[a]]$ is a neutral term, then $[[a]]$
  semantically inhabits $[[A0]]$. By \rref{I-D}, we pick $[[dummy]]$
  for $[[a]]$ and deduce that $[[B0 {dummy / x}]]$ is weakly
  normalizing. By Lemma~\ref{lem:wnanti}, we conclude that $[[B0]]$ is
  also weakly normalizing.
\end{proof}

\subsection{Soundness}
\label{sec:soundness}
To define semantic well-typedness, we need to first define the notion
of valid substitutions, sometimes also referred to as valuations.
\begin{definition}[Valid Substitutions]
  \stack{.~}\footnote{\suppl{theories}{soundness.v}{$\rho$\_ok}}
  \label{def:semwf}
  A substitution map is valid substitution 
  from $[[G]]$ to $[[D]]$,
  written $\sws{[[D]]}{\rho}{[[G]]}$,
  if for every $[[x : l A in G]]$,
  $[[| D | |- rho(x) : l]]$ holds,
  and for all $i$, $S$ such that
  $\interp{[[|D|]]}{[[i]]}{[[A { rho }]]}{S}$
  and $\member{\rho(x)}{[[l]]}{S}$.
  % Intuitively, $\rho$ replaces the variables listed by $[[G]]$,
  % and the terms $\rho$ replaces them by have free variables in $[[D]]$.
\end{definition}

Next, we define semantic typing based on the definitions of valid
substitutions and the logical predicate.
\begin{definition}[Semantic well-typedness]
  \label{def:semwt}
  \stack{.~}\footnote{\suppl{theories}{soundness.v}{SemWt}}
  A term $[[a]]$ is semantically well typed with type $[[A]]$
  at level $[[l]]$ under context $[[G]]$,
  written $\swt{[[G]]}{[[a]]}{[[l]]}{[[A]]}$,
  if for every $\rho$, $[[D]]$,
  given $\sws{[[D]]}{\rho}{[[G]]}$,
  the term $[[a {rho}]]$ semantically inhabits the type $[[A {rho}]]$
  under the grading context $[[|D|]]$.
\end{definition}

Given a valid substitution map $[[rho]]$ from
$[[G]]$ to $[[D]]$, the validity of $[[rho]]$ does not necessarily
imply the well-formedness of the types in $[[G]]$. The universal
quantifier in the definition of $\sws{[[D]]}{\rho}{[[G]]}$ does not
imply that there always exists an interpretation
for types in $[[G]]$. Instead, the existence of interpretations
for types in $[[G]]$ is separately provided by the semantic
context well-formedness judgment, written $\swf{[[G]]}$, which we
inductively define as follows.
\begin{mathpar}
  \infer[\ottdrulename{SWf\_nil}]{~}{\swf{[[nil]]}} \and
  \infer[\ottdrulename{SWf\_cons}]{
    \swf{[[G]]} \\
    \swt{[[G]]}{[[A]]}{[[l]]}{[[Univ i]]} }{ \swf{[[G ++ x : l A]]}
  }
\end{mathpar}

\section{Notes}

The level of the scrutinee must be bounded by the level of the overall eliminator.
In particular, in \rref{Wt-J}, the level $[[l]]$ of an equality proof $[[p]]$
must be bounded by that of its elimination $[[J c l p]]$,
and in \rref{Wt-Let}, the level $[[l]]$ of a pair $[[a]]$
must be bounded by that of its elimination $[[let (l0 x, y) = l a in b]]$.
The bound is required to prove the simulation property (\cref{lem:simulation}).
Suppose that scrutinees could instead be typed at any level.
First, the indistinguishability rules need to be updated
so that scrutinees are indistinguishable if their level is higher
than that of the overall eliminator, just like in \rref{I-App}.
The modified premises are highlighted in \hlcolor{} below.
%
\begin{mathpar}
  \setlength{\fboxsep}{1.5pt}
  \infer[\ottdrulename{I\_J\_bad}]{
    \mathcolorbox{\hlcolor}{[[E |- p0 == p1 @ l l0]]} \\
    [[E |- c0 == c1 @ l]]
  }{
    [[E |- J c0 l0 p0 == J c1 l0 p1 @ l]]
  }
  \and
  \infer[\ottdrulename{I\_Let\_bad}]{
    \mathcolorbox{\hlcolor}{[[E |- a0 == a1 @ l l1]]} \\
    [[(# E ++ x : l0 #) ++ y : l1 |- b0 == b1 @ l]]
  }{
    [[E |- let (l0 x, y) = l1 a0 in b0 == let (l0 x, y) = l1 a1 in b1 @ l]]
  }
\end{mathpar}

As concrete examples, by these alternate rules,
supposing $[[J c H p]]$ were well typed in context $[[G]]$
at level $[[L]]$ with $[[G |- p : H a ~ L a]]$,
we can conclude that $[[| G | |- J c H refl == J c H p @ L]]$.
The problem is that the left-hand side reduces to $[[c]]$,
while the right-hand side does not necessarily reduce to something indistinguishable from $[[c]]$,
thereby violating the simulation property.
The same issue arises with pairs, where we may be able to conclude that
$[[| G | |- let (H x, y) = H (H a, b) in c == let (H x, y) = H d in c @ L]]$,
and the left-hand side reduces to $[[c {a / x, b / y}]]$,
while the right-hand side again does not necessarily reduce to something indistinguishable from it.
Even if the context were empty, the simulation property still cannot be proven
without knowing \apriori that a closed proof of equality $[[p]]$ normalizes to $[[refl]]$,
or that a closed term of a pair type normalizes to a pair.

The one exception is the eliminator for the empty type,
whose scrutinee may be well typed at any arbitrary level in \rref{Wt-Absurd}.
Since $[[absurd b]]$ has no reduction rules beyond the congruence \rref{P-Absurd},
ignoring $[[b]]$ in \rref{I-Absurd} will not violate the simulation property.
